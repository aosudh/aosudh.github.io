01 · CLUSTER STABILITY

大规模智算集群稳定性与可靠性工程

围绕多机多卡智算集群的上线验收与长周期稳定性测试，构建从单卡满载烤机、功耗与热节流监控到跨节点集合通信压测的端到端验收基线；深度定位 PCIe 链路降级、BAR0 MMIO 访问异常、GPU 掉卡（Fallen off the bus）、TMA/mbarrier 挂死与静默性能抖动等生产级疑难故障。

02 · ACCELERATOR BENCHMARKING

异构计算卡微架构剖析与极限速率实测

覆盖 NVIDIA Hopper / Blackwell / Rubin、DGX Spark、Jetson Thor 及国产算力卡（如 MTT S5000）的真实算力墙、显存带宽与发射占空比表征；结合 DCGM 硬件计数器、Nsight Compute 与底层 CUTLASS / CUDA 内核追踪，量化多精度矩阵算力、特供 SKU 限速机制与端到端推理吞吐收益。

03 · FABRIC & NETWORKING

高速互联拓扑与数据中心交换网络

深挖 GPU↔GPU PCIe P2P、GPUDirect RDMA（DMA-BUF / nvidia-peermem）、NVLink-C2C 与 MTLink 互联带宽瓶颈，以及多卡 NCCL / MCCL AllReduce 通信效率；涵盖白盒与品牌 100G/400G 交换机（HPE / Celestica / Mellanox SN2100）的 SONiC / Onyx / ONIE 平台适配、端口拆分验证与带外运维体系。

04 · FIRMWARE & HARDWARE ATLAS

底层固件逆向、恢复与硬件资料库

涉及 ConnectX-7/8/9 网卡固件二进制与 PSID 谱系逆向、CH347 / MTUSB / FS5 双份 NV_DATA 闪存级救砖、OpenRM / GSP-RM 驱动栈源码消融，以及 Jetson 载板设备树与嵌入式启动链排错；持续维护 Ampere → Rubin 全量 PCI Device ID 对照表与 Jetson/Tegra 模组料号图谱。
