八、Linux 主线驱动、PCI-SIG 与周边 ID 补充

  • Linux nvgrace-gpu & PCI-SIG CXL DVSEC：主线 drivers/vfio/pci/nvgrace-gpu/main.c 收录 5 个 Grace 一致性内存 VFIO ID（2342、2345、2348、2941、31C2），并通过 PCI-SIG CXL DVSEC 探测 Blackwell-Next / Rubin 显存就绪状态。
  • Linux Rust 驱动 nova-core：drivers/gpu/nova-core/gpu.rs 已覆盖 GA10x / GH100 / AD10x / GB10x / GB20x，并明确注释 Rubin 时代 boot0 将耗尽新增 GPU ID 位宽。
  • 未计入主表的周边 ID：pci.ids v2026.11.19 同期出现 2F88（T256）、2F95–2F99（TB500 RP x16~x1）与 200A（NPU），属 Tegra 根端口或非独立 GPU 功能。
